# Lista IPTV M3U

Repositório com a lista IPTV formatada em [`lista.m3u`](./lista.m3u) contendo **62 canais** organizados em **5 categorias**.

## Como usar o link direto (Raw) no seu Player IPTV

Depois de publicar este repositório como **Público** no GitHub:

1. Abra o arquivo [`lista.m3u`](./lista.m3u) aqui no GitHub.
2. Clique no botão **Raw** no canto superior direito do arquivo.
3. Copie a URL da barra do navegador (formato `https://raw.githubusercontent.com/SEU-USUARIO/SEU-REPOSITORIO/main/lista.m3u`).
4. Cole essa URL no seu player IPTV (VLC, TiviMate, IPTV Smarters, Kodi, OttPlayer ou SS IPTV).
